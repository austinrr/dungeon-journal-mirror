DungeonJournal - TBC Anniversary
By Exehn

Browse Classic and Burning Crusade dungeon and raid bosses, loot, quests,
quest chains, NPC locations and instance maps. Includes loot favourites,
filters, heroic dungeon information and a gem finder.

INSTALLATION
Extract the ForeverDungeonJournal folder into:
World of Warcraft/_anniversary_/Interface/AddOns/
Keep the folder name ForeverDungeonJournal; the artwork uses this path.
Enable Dungeon Journal - TBC Anniversary on the character selection screen.

USAGE
Type /dj to open or close the journal.
Use the Vanilla, TBC and Raids buttons to switch galleries.
Addon preferences are available in the game's addon settings.

COMPATIBILITY
This package is for The Burning Crusade Anniversary (interface 20506).
The Forever edition is available separately on the same CurseForge project.
